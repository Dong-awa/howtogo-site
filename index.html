然后像用地图软件一样出发

问道（HowToGo）把 Xaero 世界地图变成一张真正能用的路网：画路、标记地点、 选目的地、选交通方式、看路线预览、跟着 HUD 走到终点。 手画的路在地图上是一条平滑曲线；阡陌交通、机械动力与 MTR 的路与线路会被自动读进来， 不用你一格一格画。世界里按 K 就能打开主界面看地图、换出行方式、开始或结束导航； 整份路网与地点还能打成一个压缩包导出、导入。

快速开始

三步，从画第一条路到跟着导航走

问道是纯客户端模组，装在自己的客户端即可，服务器上什么都不用加。

装好前置，进游戏

把 Xaero's World Map 与问道放进 mods/。机械动力、MTR 都是可选的： 装了就会被自动读进来，没装也不影响其它功能。

打开世界地图，按 R 开始画路

左键落点、右键结束，< > 换等级（高速 / 公路 / 小路 / 铁路 / 水路 / 冰道）， 按 N 命名，按 P 标地点。离得近的节点与路段会自动吸附。

选个目的地，出发

按 Ctrl + 左键直接在地图上点目的地，或按 K 打开主界面——0.2.3 起 导航仪物品已经移除，K 是打开本模组界面的唯一入口。先看路线预览与预计时间， 再按「导航到这里」，剩下的交给 HUD 与语音播报。

功能

一张地图，一条路网，一次说走就走

从画路到出发之间，不该隔着十几次界面切换。

画路与维护

六个道路等级、自动吸附、整条命名、地点标记，撤销重做 64 步。 在路段中间落点会真正拆分路段并在交点建立节点。

  • 路段交叉、差一格没接上，只要「看着连上了」就会被自动修好
  • 地点分四类：地点 / 资源点 / 商店 / 站点
  • 每个地点都能写描述、贴标签、标收藏（0.2.3）
  • 画出来的线是平滑曲线：寻路、测距与存档里的整数顶点一行没动

实时导航

步行 / 驾车 / 公共交通，三种方式走的道路不同，所以同一组起终点会得到不同的路线。

  • 最快时间 ↔ 最短距离，可避开某类道路，可优先大路
  • 先预览后出发；不拉直线，绕远或走不通就直说
  • 步行离开路面最多 32 格（walk_offroad_blocks），驾车不再越野
  • 世界里按 K 打开主界面：看地图、选目的地、结束导航、切换出行方式
  • HUD 面板 + 语音播报（转弯前、现在转弯、到达、偏航）
  • 也能把导航画到 Xaero's Minimap 上，屏幕上只留一张精简卡片（0.2.3；本次仅 1.21.1 NeoForge 编入）

界面主题与游戏内设置

0.2.3 起界面有三档主题：深色、浅色、跟随天光自动切换；主界面（K）标题栏的 「设置」把十五项常用配置搬进了游戏，分五组。

  • 浅色不是把黑色反过来：白底上重新取过文字与含义色的对比度
  • 「跟随天光」读世界天空亮度的实时值；地狱、末地与没有天空的维度永远是黑色
  • 改一下立刻保存，没有「应用」按钮；有依赖的项变灰并写明原因
  • 颜色、逐级容差、方块 id 与 webmap_port 仍留在 TOML

公共交通线路

在世界地图上按 L 打开线路配置：左列线路、中列站点顺序、右列可加的站点， 一屏建完一条线路。

  • 站点来源：自己标记的站点 + 机械动力车站 + MTR 车站
  • 接不上一站的站点直接标红，出发前就能看见
  • 换乘站在两条线共用时显示为橙色方块
  • 线路按类型（铁路 / 水路 / 公路 / 冰道）取色，颜色可以自己改

机械动力铁路

装了 Create，它的铁轨会以曲线形式自动画到地图上，无需手画；读不到轨道图时回退为扫描轨道方块。

  • 车站成为可导航的目的地
  • 铁路只读，但可以整条命名，名字存在单独的文件里
  • 画路时可以吸附到铁轨上，把路正好接上去
  • 贝塞尔曲线保留原采样再平滑，不再先四舍五入到方块
  • 端点相接的短轨道先拼成长段，选中、命名与寻路都变干净

MTR 线路识别

装了 MTR（4.0.4 及以上），它的车站与线路会被读成问道自己的站点与线路：列车 / 缆车算铁路，船算水路。

  • 每条线路都能选择「沿这条线标记轨道」，让车程沿 MTR 真正铺的轨道计算
  • 只读线路可一键「复制为我的」再随意修改
  • 走出 MTR 同步范围也不会丢：读到过的车站、线路、轨道都会被记住
  • 同名车站按 256 格上限合并成一个地点：列表一条、地图一个标记
  • MTR Map Overlay 的「线路 / 轨道」开关会被记住，下一局恢复
  • 服务端也装本模组与 MTR 时，整张路网会同步到客户端（0.2.3，仅 1.20.6 / 1.21.1）

阡陌交通 RoadWeaver

装了阡陌交通，它自动生成的道路会被读进来、画在世界地图上、参与寻路，它连接的村落与小屋也成为目的地。 全反射读取，没装也不会崩。

  • 路一律按「小路」读，可用 roadweaver_road_class 强制一个等级
  • 路口就是它自己说过的路口：两条路共享点位才算连通，交叉而过的不猜
  • 联机在别人的服务器上时，这一局要先按一次它的路网地图（H）

看得清的地图

左上角的「地图显示」面板可以逐个开关道路等级、地点类型与公共交通线路，面板还能拖着走。

  • 缩小地图时按等级自动取舍：小路 → 公路 → 水路 → 铁路，高速与冰道永不隐藏
  • 道路按层叠放：高架压在自己跨过去的地面路之上，隧道在最下面
  • 名字的字号不超过路的宽度，路太细时先不写；长路沿路每隔约 190 像素写一个
  • 地点名、铁路名、道路名共用一张「已占位置」表，排不下就不画
  • 每个道路等级的颜色都能在 road_colors 里自己定，改完不用重启
  • 面板是屏幕覆盖层，不会被地图上的线路与文字盖住

浏览器地图

/howtogo webmap 在本机开一个小服务，把游戏里那张地图画成浏览器里的俯视地图： 阡陌交通、机械动力、MTR 的只读图层也在里面，按道路等级取色、带平滑曲线。细节见 浏览器地图。

  • 只监听 127.0.0.1：配置里没有能把它放到局域网上的开关，读的始终是客户端自己那份
  • 只读图层会在鼠标读数与统计里标出来源，侧栏多一行「自动识别」
  • 页面与 html2canvas 都在 jar 里，离线可用，可导出 2 倍分辨率 PNG
  • 手动启动不再弹「是否打开链接」，直接开系统默认浏览器

安装

需要什么，装到哪里

问道是纯客户端模组：只装在客户端，服务器上不需要安装，也不会要求服务器装任何东西。

模组 必要性 作用
Xaero's World Map 必需 所有道路与路线都画在它上面
XaeroLib 必需 由 World Map 提供；26.x 起随它以嵌套 jar 分发，不用单独下载
Xaero's Minimap 可选 路标点可作为目的地
Create 机械动力 可选 铁轨与车站自动识别
MTR 可选 车站与线路自动识别（4.0.4 及以上）
阡陌交通 RoadWeaver 可选 它生成的道路、村落与小屋读进地图与目的地
MCPhone 可选 手机里多一个「问道导航」应用

支持的版本：Minecraft 1.20.1 – 26.3， Fabric 与 NeoForge 两条线。0.2.3 共 21 个构建（Fabric 11 个、NeoForge 10 个；1.20.1 没有 NeoForge）， 不支持 Forge。

下载文件名形如 howtogo-0.2.3+mc1.21.1-neoforge.jar， 把对应版本的那一个放进 mods/。0.2.3 的包名不再带 pre1 后缀。

测试情况：21 个构建全部通过编译与静态检查，纯逻辑回归 1005 项全过；其中 18 个节点用真实客户端跑过 9~10 项功能自检（路网、线路、规划、存档、地点详情、导出导入、网页地图、界面主题）， Fabric 的 26.1 / 26.2 / 26.3 只验证到能启动、能进世界、路网读取正常。 遇到问题请附上 latest.log。

可选模组全部通过注册名或反射读取，因此版本不合也不会让游戏起不来——最差的结果是那个图层为空。

数据存在客户端的 config/howtogo/ 下，按存档 / 服务器分开： 单人存档按存档名，多人按服务器地址。换服务器不会串数据。

0.2.2 起中文存档的数据目录改用拼音命名（sp_新世界 → sp_xin_shi_jie），第一次打开某个世界时自动整目录改名，升级不用做任何事； 代价在降级：用 0.2.2 存过档再退回 0.2.1，那个世界的路网会是空的。 详见 数据目录与迁移。
