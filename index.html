问道（HowToGo）把 Xaero 世界地图变成一张真正能用的路网：画路、标记地点、 选目的地、选交通方式、看路线预览、跟着 HUD 走到终点。 机械动力的铁轨和 MTR 的线路会被自动读进来，不用你一格一格画； 路网还能一键在浏览器里打开，按层看清高架与隧道，并导出成图片。

快速开始

三步，从画第一条路到跟着导航走

问道是纯客户端模组，装在自己的客户端即可，服务器上什么都不用加。

装好前置，进游戏

把 Xaero's World Map 与问道放进 mods/。机械动力、MTR 都是可选的： 装了就会被自动读进来，没装也不影响其它功能。

打开世界地图，按 R 开始画路

左键落点、右键结束，< > 换等级（高速 / 公路 / 小路 / 铁路 / 水路 / 冰道）， 按 N 命名，按 P 标地点。离得近的节点与路段会自动吸附。

选个目的地，出发

按 Ctrl + 左键直接在地图上点目的地，或拿导航仪右键打开选择界面。 先看路线预览与预计时间，再按「导航到这里」，剩下的交给 HUD 与语音播报。

功能

一张地图，一条路网，一次说走就走

从画路到出发之间，不该隔着十几次界面切换。

画路与维护

六个道路等级、自动吸附、整条命名、地点标记，撤销重做 64 步。 在路段中间落点会真正拆分路段并在交点建立节点。

  • 路段交叉、差一格没接上，只要「看着连上了」就会被自动修好
  • 地点分四类：地点 / 资源点 / 商店 / 站点

实时导航

步行 / 驾车 / 公共交通，三种方式走的道路不同，所以同一组起终点会得到不同的路线。

  • 最快时间 ↔ 最短距离，可避开某类道路，可优先大路
  • 先预览后出发；不拉直线，绕远或走不通就直说
  • HUD 面板 + 语音播报（转弯前、现在转弯、到达、偏航）

公共交通线路

在世界地图上按 L 打开线路配置：左列线路、中列站点顺序、右列可加的站点， 一屏建完一条线路。

  • 站点来源：自己标记的站点 + 机械动力车站 + MTR 车站
  • 接不上一站的站点直接标红，出发前就能看见
  • 换乘站在两条线共用时显示为橙色方块

机械动力铁路

装了 Create，它的铁轨会以曲线形式自动画到地图上，无需手画；读不到轨道图时回退为扫描轨道方块。

  • 车站成为可导航的目的地
  • 铁路只读，但可以整条命名，名字存在单独的文件里
  • 画路时可以吸附到铁轨上，把路正好接上去

MTR 线路识别

装了 MTR，它的车站与线路会被读成问道自己的站点与线路：列车 / 缆车算铁路，船算水路。

  • 每条线路都能选择「沿这条线标记轨道」，让车程沿 MTR 真正铺的轨道计算
  • 只读线路可一键「复制为我的」再随意修改
  • 走出 MTR 同步范围也不会丢：读到过的车站、线路、轨道都会被记住

看得清的地图

左上角的「地图显示」面板可以逐个开关道路等级、地点类型与公共交通线路，面板还能拖着走。

  • 缩小地图时按等级自动取舍：小路 → 公路 → 水路 → 铁路，高速与冰道永不隐藏
  • 道路按层叠放：高架压在自己跨过去的地面路之上，隧道在最下面
  • 名字的大小跟着缩放走，线上名字顺着线的方向写
  • 面板是屏幕覆盖层，不会被地图上的线路与文字盖住

浏览器地图

/howtogo webmap 在本机开一个小服务，把当前维度的路网画成浏览器里的俯视地图， 地址以可点击的链接发在聊天栏；细节见 浏览器地图。

  • 只监听 127.0.0.1：配置里没有能把它放到局域网上的开关
  • 页面与 html2canvas 都在 jar 里，离线可用，可导出 2 倍分辨率 PNG
  • 按道路等级与层过滤，状态栏报光标下最近的路或地点

安装

需要什么，装到哪里

问道是纯客户端模组：只装在客户端，服务器上不需要安装，也不会要求服务器装任何东西。

模组 必要性 作用
Xaero's World Map 必需 所有道路与路线都画在它上面
XaeroLib 必需 随 World Map 一起提供
Xaero's Minimap 可选 路标点可作为目的地
Create 机械动力 可选 铁轨与车站自动识别
MTR 可选 车站与线路自动识别
MCPhone 可选 手机里多一个「问道导航」应用

支持的版本：Minecraft 1.21.1，NeoForge 21.1.x（21.1.0 ~ 21.1.x）。

可选模组全部通过注册名或反射读取，因此版本不合也不会让游戏起不来——最差的结果是那个图层为空。

数据存在客户端的 config/howtogo/ 下，按存档 / 服务器分开： 单人存档按存档名，多人按服务器地址。换服务器不会串数据。
