安装与前置

问道是纯客户端模组：装在你自己的客户端就够了，服务器上不需要装它， 它也不会向服务器要求任何东西。换句话说，在任何服务器里，你都能独自使用它； 你画的路、标的地点只存在于你的客户端。

版本要求

项目 要求
Minecraft 1.21.1
NeoForge 21.1.x（21.1.0 及以上，21.2 之前）
运行侧 客户端（dist = CLIENT）
模组 ID howtogo
当前版本 0.2.1

版本范围是写死的，不是「大概能用」：NeoForge 只声明 21.1.x、Minecraft 只声明 1.21.1。一个错误的上限比缺少一个功能更糟——它会让人在从没测试过的版本上加载，然后把崩溃当成 bug 报上来。

需要哪些模组

模组 必要性 说明
Xaero's World Map 必需 所有道路、线路与路线都渲染在它上面。缺少时模组会在日志里报错并停用渲染层。
XaeroLib 必需 随 World Map 一起提供，不需要单独下载。
Xaero's Minimap 可选 装了以后，小地图上你插的路标点会出现在目的地列表里。
Create（机械动力） 可选 自动识别铁轨与车站，见 机械动力铁路。
MTR（我的世界铁路） 可选 读取 MTR 的车站与线路，见 MTR 集成。
MCPhone 可选 在手机里多出一个「问道导航」应用，等于一个打开目的地选择界面的入口。

所有可选模组都是通过方块注册名或反射读取的： 问道的构建脚本里没有任何一个的依赖。这让「没装」这件事变得无害——对应图层为空， 其它功能照常；也让它们换版本、改包名时，问道最多是读不到，而不是编译不过或直接崩。

安装步骤

  1. 给 1.21.1 装好 NeoForge 21.1.x，确认能正常进入游戏。
  2. 把 Xaero's World Map（1.21.1 / NeoForge 版）放进 mods/。
  3. 把 howtogo-0.2.1.jar 放进同一个 mods/。
  4. 启动游戏。日志里出现 [HowToGo] constructed 就说明模组已经加载。

想要识别机械动力铁路或 MTR 线路，再把对应模组也放进 mods/；它们是随时可以加减的—— 加进来图层立刻有内容，拿掉图层立刻为空，你的路网不会因此受损。

进游戏后先确认这三件事

  1. 打开世界地图，左上角应该出现「地图显示」面板（可以拖动、可以卷起）。 看不到它，多半是 Xaero 的世界地图没装或版本不对。
  2. 在世界地图上按 R，屏幕左下角出现绘制状态与路网统计、右下角出现快捷键列表， 说明编辑模式已经打开。
  3. 拿一个导航仪（或按 Ctrl + 左键点地图）确认选择目的地界面能打开。

地图显示面板的默认位置是左上角往里一点。如果那里正好被别的模组（例如机械动力自己的界面） 占着，直接拖它的标题行换个位置即可，位置会被记住。

数据放在哪

所有数据都在客户端的 config/howtogo/ 下，按存档分开： 单人存档按存档名（sp_<存档名>），多人服务器按服务器地址（mp_<地址>）。 坐标只在一个维度里有意义，所以文件名里还带着维度。

文件 内容
<维度>.json 道路网络：节点、路段、名称、地点与地点类型。
<维度>-lines.json 公共交通线路：线路名、类型、按顺序的站点。
<维度>-rail-names.json 自动识别铁路的名称（单独一个文件，因为铁路图层每秒重建）。
route_preferences.json 上次选择的交通方式与路线偏好。
map_filter.json 地图显示面板的开关、卷起状态与位置（与存档无关）。
../howtogo-client.toml 客户端配置，见 配置与数据文件。

想备份路网，复制整个 config/howtogo/ 目录即可；想在不同电脑之间搬家，也是同一个目录。 反过来，删掉模组的 jar 不会删掉这些文件——路网是你的数据，不是模组的缓存。

因为它是纯客户端的，别的玩家看不到你画的路，也看不到你的导航。 这是设计选择（不需要服务器配合、也不用担心服务器权限），不是缺陷。
